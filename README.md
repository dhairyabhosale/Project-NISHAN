# NISHAN

Offline scaffold for the PM-KISAN payment-trace experience.

## Run

`npm install && npm run dev`

Check types with `npx tsc --noEmit`.

## Real in this scaffold

- Next.js App Router routes for lookup, a case, assisted mode, and disclosure.
- A keyed English/Hindi content catalogue and slot resolver.
- A rendered Money Rail using the hardcoded sample case.
- Status-code-to-plain-language mapping, responsive hand-rolled UI, and a disabled Bhashini voice affordance.
- PostgreSQL-compatible SQL schema definition and append-only event shape.

## Stubbed

- Diagnosis engine and blocker evaluation.
- All seven mocked government-system integrations.
- Database connection, persistence, consent persistence, and event writing.
